To  understand the callLater function, you should read the following document first:

In Qt Quick (QML), Qt.callLater() is a built-in utility that schedules a function or signal to run slightly later—specifically, as soon as the QML engine returns to the main event loop.

While it might sound like a simple delay tool, it is actually a critical UI optimization mechanism designed around two specific behaviors: deferred execution and automatic deduplication.

The Two Core Behaviors
1. Deferred Execution
When a property changes in QML, it can trigger a massive cascade of bindings and signal handlers. Running a heavy calculation right in the middle of this cascade can cause visual stuttering or logical errors if other properties haven't finished updating yet. Qt.callLater() pushes your function out of this chaotic evaluation phase and queues it safely in the event loop to run when the UI state has settled.

2. Automatic Deduplication (Batching)
This is where the function really shines. If Qt.callLater(myFunction) is triggered ten times in a single event loop cycle, the QML engine intercepts them and collapses them so myFunction only executes once. This eliminates redundant processing.
